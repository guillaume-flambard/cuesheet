# MCP contract

Owner-configured local stdio server. Six tools: list_missions {}, get_mission {missionId}, start_mission {project,objective,requestId}, steer_mission {missionId,text,expectedRevision,requestId}, stop_mission {missionId,requestId}, get_human_delta {missionId}. Mutations are model-visible only; app can call reads. Start uses configured project IDs only. Duplicate identical request IDs return the prior result, conflicting reuse refuses. Revision mismatch refuses steering. Commands/slash syntax never pass as natural steering. Stop preserves the open goal and journals.

MCP Apps resource ui://cuesheet/mission-control/v1 with MIME text/html;profile=mcp-app. get_mission/start_mission link this resource; other calls remain data-first. structuredContent carries concise semantic state; full detail in _meta.mission. Text fallback names state, actual verification and required action. Explicit extension negotiation handled by the SDK. UI calls get_mission through official App class, polls only while visible, no browser network permission required. No raw shell, worker IDs as targets, path inputs or permissions from the model/UI.

Documented implementation line: @modelcontextprotocol/ext-apps 1.1.2 + SDK 1.32.0, pinned compatible SDK1 peers; current ext-apps2 uses SDK2 packages and is not silently mixed into the documented v1 quickstart. Resource and bridge follow stable 2026-01-26 specification.

Primary sources consulted: [stable specification](https://github.com/modelcontextprotocol/ext-apps/blob/main/specification/2026-01-26/apps.mdx), [official executable quickstart](https://apps.extensions.modelcontextprotocol.io/api/documents/Quickstart.html), [ChatGPT UI](https://developers.openai.com/plugins/build/chatgpt-ui), [Claude support](https://claude.com/blog/interactive-tools-in-claude). Adaptation from quickstart: same SDK resource/tool/App handshake, replaces time fixture with real runtime journal projection and owner-controlled mutations. ChatGPT documents standard bridge, text fallback and host-controlled sandbox. Claude documents interactive connectors, not evidence that this local server is installed there. Local stdio is not a publicly reachable ChatGPT connector. Remote OAuth/HTTPS/tunnel is deferred; no server exposure or account configuration is changed.
