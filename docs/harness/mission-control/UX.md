# Views

Card: action requirement first, then project/objective, observed status and semantic steps. No percentage if completion denominator is unknown. Worker results say observed/proposal, never verified.

```text
Cuesheet                         Running
Inspect recovery without changing files

No action required
Reading the declared source
2 active workers (only if observed)

Inspect                       Refresh
```

Inspector: objective/corrections, available execution graph, workers, verification receipts, decisions, failure/recovery and Human Delta. No raw logs or private transcripts. Source sequence is a detail, not default card decoration.

Human Delta: exact pending check confirmation, reason it belongs to the human, current revision and preserved constraints. A failed tool is a failure, not a human gate. The card must not claim all machine work is exhausted when it is not.

Design plan: host background white #ffffff, ink #202a35, secondary #536172, border #dce1e7, restrained blue #245cb3, amber #855400. Native system sans for text, no external fonts. Left aligned, single reading column, spacious objective and dense evidence rows; action requirement is the memorable element. Avoid decorative dashboards; rows only where data is actually parallel. Host theme/CSS tokens and light/dark context override local fallbacks.

Empty means no admitted mission; loading never invents progress; failure preserves last observed state and displays stale/disconnected explicitly. Inline default, inspector can request fullscreen when supported and falls back to expansion. Human Delta is a focused third view. Keyboard focus visible, narrow layouts wrap, reduced motion has no effect because no decorative animation. Refresh is read-only; mutations use conversation/host tools, never an iframe-only approval.
